## METAR Reader

A Flask app that turns an airport's METAR into a plain-English weather report.
Data comes from the [Aviation Weather Center](https://aviationweather.gov/data/api/).

```
uv run app.py        # http://127.0.0.1:5000
uv run pytest        # run the tests
```

Requires [uv](https://docs.astral.sh/uv/); it creates the environment and installs dependencies automatically.
